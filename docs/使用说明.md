# Codex Pulse 使用说明

适用版本：1.1.2。支持 Apple Silicon、macOS 14+。

## 下载安装

在 [版本页面](https://github.com/ufoazst/codex-pulse/releases/tag/v1.1.2) 下载 `CodexPulse-1.1.2-arm64.dmg`。打开后，把 `CodexPulse.app` 拖入「应用程序」。如果已有旧版本，请先退出旧版再替换。

从「应用程序」启动一次，等待出现 token 与额度数据，然后推出 DMG。不要同时启动 DMG、下载文件夹和「应用程序」中的多个副本。

### 安装限制

该版本采用 ad-hoc 签名，未经过 Apple 公证，不是 App Store 应用。在其他 Mac 上，Gatekeeper 可能阻止启动或提示无法验证开发者。确认下载来源、校验文件并理解该版本的实验性质后，再决定是否使用；不建议关闭系统安全保护。也可以等待后续经过开发者签名和公证的版本。

本工具还依赖可用的 `/usr/bin/python3` 与已登录的 Codex。安装包不会安装这些依赖。

## 添加桌面小组件

1. 先打开 Codex Pulse，并等待首次同步完成。
2. 右键桌面空白处，选择「编辑小组件」。
3. 搜索 **CodexPulse**，找到 **Codex 用量**。
4. 选择小、中、大尺寸，拖到桌面并点击「完成」。

| 尺寸 | 内容 |
| --- | --- |
| 小 | 今日 token、首个额度窗口、更新时间 |
| 中 | 今日 token、缓存量、主要账户额度窗口和重置时间 |
| 大 | 中号内容，以及今日消耗最高的 4 个模型和次要额度窗口 |

小组件配色跟随系统；点击小组件会打开主应用并请求刷新。完整模型列表可以在主应用查看。

## 菜单栏与浮窗

菜单栏的波形图标旁显示今日 token。点击后展开详情，切换「今日 / 近 7 天 / 全部」查看模型消耗。近 7 天包含今天和前 6 个自然日，按 Mac 本地时区计算。

右上角刷新按钮可以手动同步。菜单栏面板中的图钉可打开常驻浮窗，浮窗中的图钉可隐藏浮窗。关闭浮窗不会退出应用；底部「…」菜单提供退出入口。

如果需要登录后启动，可在 macOS「系统设置 → 通用 → 登录项」中添加安装后的 Codex Pulse。

## 用量、额度和更新时间

- **输入 token** 包含缓存输入，**输出 token** 包含推理输出；这些子项不再重复加到总量。
- 模型名来自本地日志，`codex-auto-review` 是日志里的审核标识，不能据此确定底层模型。
- 额度按服务端返回的额度组展示，共享额度不等于每个模型各有独立额度。
- 重置时间来自服务端，按本地时区显示。倒计时到期后等待服务端更新，不自行假设额度已清零。
- 额度查询失败时保留上次快照及时间，不把缺失值当成 0%。
- 主应用约每 60 秒采集；小组件由 macOS 调度刷新，可能有延迟。
- 小组件超过 5 分钟的快照会显示过期状态；跨日未同步时今日 token 显示「—」。

## 常见问题

**没有找到小组件**：确认应用已放在「应用程序」并打开过一次，再重新打开小组件图库搜索。仍然没有时，请提供 macOS 版本和应用版本反馈。

**用量是空的或读取失败**：确认 Codex 已使用过并生成本地日志，且 `/usr/bin/python3` 可运行。等待首次扫描结束，或点击刷新。

**有 token 但额度无法更新**：检查 Codex 的登录状态与网络连接。日志统计可以离线读取，在线额度需要 Codex 账户服务可用。

**多个同名图标**：只保留「应用程序」中的一份，退出安装磁盘或下载目录中的旧副本，推出安装 DMG。不要删除 Codex 自身的数据目录。

**退出主应用后小组件不更新**：小组件只展示汇总快照，持续采集需要菜单栏应用运行。

## 数据与隐私

数据源为 `~/.codex/sessions`、`~/.codex/archived_sessions`，或由 `CODEX_HOME` 指定的目录。不会上传会话日志。

用量缓存位于 `~/Library/Caches/CodexPulse`；小组件快照位于 `~/Library/Application Support/CodexPulse/Widget/snapshot.json`。后者只包含汇总展示数据，没有聊天正文、日志路径或账户标识。

本地日志缺失、分叉记录或 Codex 日志格式变更可能影响统计，不能将该工具作为账单审计依据。

## 卸载

退出 Codex Pulse，移除桌面上的小组件，再将「应用程序」中的 CodexPulse.app 移到废纸篓。若要清除本工具的缓存，可单独删除上文列出的 CodexPulse 缓存与快照目录。请保留 `~/.codex`，它属于 Codex 本身。
